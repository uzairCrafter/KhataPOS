## 📌 Project Overview
KhataPOS is a web application designed for small-to-medium retail businesses to manage daily sales, stock inventory, and customer ledgers efficiently.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, EJS
- **Backend:** Node.js, Express.js
- **Database:** SQLite
